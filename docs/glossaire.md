# Glossaire de l'interface

Vocabulaire constant à utiliser dans toute l'interface et toute la documentation
utilisateur (section 6). Complété à chaque lot.

| Terme retenu | À ne pas utiliser | Remarque |
| --- | --- | --- |
| Corbeille | poubelle | Désigne la Corbeille Windows (`IFileOperation`) |
| Zone de notification | systray, barre des tâches | Terme officiel Windows |
| Tableau de bord | dashboard | Nom de la page d'accueil |
| Lecture seule | mode dégradé | Utilisé quand une migration a échoué (section 14) |
| Module | plugin, extension | Désigne AppManager, NetWatch, etc. |
| Fichier à la demande | fichier non téléchargé, fichier fantôme | Placeholder OneDrive (section 11) : jamais ouvert ni lu par le scan |
| Jonction | lien symbolique de dossier | Point de montage NTFS ; distincte d'un symlink, jamais suivie par le scan |
| Lien physique | raccourci, duplicata | Plusieurs chemins vers le même contenu réel sur disque (hardlink) ; compté une seule fois |
